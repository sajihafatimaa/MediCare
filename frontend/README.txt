MediCare - Hospital Management System (HTML and CSS only)

HOW TO OPEN
  1. Unzip the file.
  2. Open the "medicare" folder and double-click index.html.
  Admin:  "Admin login" -> type anything -> Sign in.
  Doctor: "Doctor login" -> choose a name -> type anything -> Sign in.

FOLDERS
  index.html   public home page
  pages/       admin login, create account, doctor logins, booking,
               payment method, doctors
  portal/      admin pages, including a view of every doctor
  doctor/      each doctor's appointments and patient details
  css/         style.css (shared), home.css, login.css, portal.css
  images/      logo, icons, illustrations and home background (hero-bg.svg)

CHANGE THE HOME BACKGROUND
  Put your photo in images/ and replace "hero-bg.svg" in css/home.css.

IMPORTANT: HTML AND CSS CANNOT DO THESE
  - Check passwords. Anyone can open any admin or doctor page.
    Do not put real patient information on this site.
  - Create accounts, or compare password with confirm password.
  - Save, edit or delete records, or book appointments.
  - Take payments, or carry booking details to the payment page.
  - Filter while typing, sort columns, or block double bookings.

  All names and records are made-up sample data.
